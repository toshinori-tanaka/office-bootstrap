# AI Office 導入ガイド — あなた専用の AI エージェント組織（◯◯-Office）

あなた専用の AI エージェント組織（秘書・各部門・品質検証つき）を、お使いの Windows PC に導入します。
**所要操作はコピペ 1 回とブラウザログイン 2 回だけ**。専門知識は不要です。

---

## 0. 事前に用意するもの（3 つ）

1. **Windows 10 / 11 の PC**（ここ数年のものなら OK。適合は導入時に自動チェックされます）
2. **GitHub アカウント（無料）** — お持ちでなければ:
   1. ブラウザで https://github.com を開く → 右上「Sign up」
   2. メールアドレス・パスワード・アカウント名（半角英数字・例 `suzuki-taro`）を登録
   3. **アカウント名をオーナー（管理者）へ伝えてください**
3. **オーナーからの招待** — 伝えたアカウント名宛に GitHub から招待メールが届くので、
   本文の **「Accept invitation」（緑のボタン）を押してください**。これで受信の準備が整います。

> 会社支給 PC の場合: 管理者権限やネットワーク制限で止まることがあります。
> その場合は本ページ末尾の「IT 部門への依頼ひな型」をそのまま送ってください。

---

## 1. 導入する（コピペ 1 回）

1. **スタートボタンを右クリック** → 「**ターミナル**」（または「Windows PowerShell」）を選ぶ
2. 下の枠の右上にあるコピーボタンで **1 行まるごとコピー** → ターミナルに**貼り付けて Enter**

```powershell
iwr -UseBasicParsing https://raw.githubusercontent.com/toshinori-tanaka/office-bootstrap/main/bootstrap.ps1 -OutFile "$env:USERPROFILE\office-setup.ps1"; powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\office-setup.ps1"
```

3. あとは**画面の日本語案内に従うだけ**です。「ユーザーアカウント制御」の確認が出たら「**はい**」を押してください。

### 途中で聞かれること（この順で・すべて画面に説明が出ます）

| 場面 | すること |
|---|---|
| PC の再起動 | Enter を押すと再起動 → **再開は自動**（始まらなければデスクトップの「セットアップを再開」をダブルクリック） |
| Ubuntu の初期設定 | 好きなユーザー名（半角英小文字）とパスワードを決めて入力（PC 内だけで使うもの） |
| 組織名 | 「◯◯-Office」の◯◯部分（半角英数字・例 `Suzuki`） |
| Claude ログイン | ブラウザが開くので、会社から案内された Claude アカウントでログイン → ターミナルに戻り `/exit` |
| GitHub 接続 | 画面に出る **8 桁コード**を、開いたブラウザに入力 |

最後に「最終自己検査」が全項目 ✓ になれば完了です。デスクトップに「**◯◯-Office**」アイコンができています。

---

## 2. 最初の一歩（組織づくり・約 5 分）

1. デスクトップの「◯◯-Office」を**ダブルクリック** → 数秒で秘書（Claude）の画面が開きます
2. `/office` と打って Enter
3. 秘書があいさつして、**あなたの仕事・目標・困りごとをヒアリング** → 合う部門を提案してくれます
4. 組織図を確認して OK すれば、あなた専用の組織が自動で組み上がります

以後は毎日、ダブルクリック → 話しかけるだけです。

---

## 3. 日常の使い方（これだけ覚えれば OK）

- **起動**: デスクトップの「◯◯-Office」をダブルクリック（またはターミナルで `office` と 6 文字）
- **画面キャプチャを渡す**: `Win+Shift+S` で範囲を撮る → Claude の入力欄で `Ctrl+V`（効かなければ `Alt+V`）
- **画面を分割してもう 1 人**: `Alt+Shift+D` → 開いた側で `office` と打つ
- **コマンド一覧**: Claude の中で `/` とだけ打つと説明付きで全部出ます（`/clear`=話題リセット等）
- **使い方に迷ったら**: 秘書に日本語で「使い方教えて」と聞く／ターミナルで `office-help`
- **調子が悪い時**: ターミナルで `office-doctor`（健康診断・何も壊しません）
- **終わり方**: `/exit` と打つ、またはウィンドウを閉じる

あなたの記録・記憶は**毎時間、あなた専用の非公開 GitHub に自動バックアップ**されます（操作不要・PC が壊れても消えません）。

---

## 4. うまくいかない時

- **途中で止まった / 閉じてしまった** → もう一度手順 1 の 1 行を実行（**続きから再開**されます）
- **「受信できません」と出る** → 招待メールの Accept がまだです。Accept してから Enter
- **原因が分からない** → ターミナルで `office-doctor` を実行し、表示された「対処」に従ってください
- **会社 PC で権限やネットワークに阻まれる** → 下のひな型を IT 部門へ
